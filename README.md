# 🌸 FocusBloom

FocusBloom é uma aplicação web de produtividade que utiliza a técnica **Pomodoro** integrada com **Inteligência Artificial e Visão Computacional** para ajudar o usuário a manter o foco durante sessões de estudo ou trabalho.

O diferencial do projeto é o uso da **webcam** para detectar distrações (como o uso do celular) e **pausar automaticamente o cronômetro**, promovendo um estudo mais consciente e equilibrado.

---

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação frontend com integração de IA capaz de:
- Gerenciar sessões de foco
- Reduzir distrações
- Aplicar regras de negócio baseadas na técnica Pomodoro
- Servir como projeto de portfólio com foco em Frontend + IA

---

## ⚙️ Funcionalidades

- ⏱️ Timer Pomodoro (foco e pausa)
- ✏️ Registro do nome da sessão de foco (ex: Matemática, Português)
- 📷 Uso da webcam para monitoramento
- 📵 Pausa automática ao detectar uso do celular
- 🔊 Alerta sonoro durante distrações
- 👁️ Alerta visual quando o foco é interrompido
- ▶️ Retomada automática do cronômetro ao recuperar o foco

---

## 🧠 Regras de Negócio (Resumo)

- O usuário inicia manualmente a sessão
- O cronômetro só roda durante o estado de foco
- Ao detectar distração → cronômetro pausa
- Alertas visuais e sonoros são exibidos durante a pausa
- O cronômetro retoma automaticamente quando a distração termina
